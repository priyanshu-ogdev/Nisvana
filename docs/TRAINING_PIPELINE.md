# Project AEGIS — Machine Learning Training Pipeline Architecture

## 1. Executive Summary

The Project AEGIS Training Pipeline is an end-to-end, reproducible deep learning framework for training, fine-tuning, and evaluating active noise cancellation (ANC), speech enhancement (SE), and acoustic gating models. It ingests standardized 48,000 Hz WebDataset shards generated by the AEGIS Data-Forge and orchestrates 5 specialized model branches optimized for edge execution on high-stress defence acoustic environments.

The training system is co-designed for the **NVIDIA DGX Spark GB10 workstation (128GB Unified Memory, CUDA 13, Grace Blackwell architecture)**, while guaranteeing deployment inference within a **≤4–8GB VRAM/RAM envelope** and **<10ms causal streaming latency** (480 samples at 48kHz).

---

## 2. Five Specialized Model Branches

| Model Key | Target Role | Architecture | Lookahead / Latency | Loss Stack & Distillation |
| :--- | :--- | :--- | :--- | :--- |
| **`aegis-se-primary`** (Model 1) | Real-time streaming speech enhancement | DeepFilterNet3 (causal ERB filterbank + complex deep filtering) | **0 ms lookahead** (zero algorithmic delay) | Multi-Res STFT + Local SNR + Speech-Gated SDR + CleanUMamba Distillation ($\lambda=0.3$) |
| **`aegis-se-escalation`** (Model 2) | High-difficulty low-SNR / blast speech enhancement | DeepFilterNet3 (high-capacity semi-causal configuration) | **10 ms / 1-chunk lookahead** output-delay buffer | Multi-Resolution STFT + Framewise Local SNR + Speech-Gated SDR |
| **`aegis-se-crosscheck`** (Model 3) | Architectural cross-validation, distillation teacher & GPU fallback | CleanUMamba (Selective State Space U-Net backbone) | Linear $\mathcal{O}(L)$ state-space representation | Full STFT Multi-Resolution Spectral Loss |
| **`aegis-clf-gate`** (Model 4) | Real-time acoustic environment & escalation classifier | 1D CNN + Adaptive Pooling (MobileNetV3-Audio class) | Fast sub-segment classification (200ms rolling window) | Weighted Cross-Entropy over 3 classes (`harmonic`, `impulsive`, `speech_dominant`) |
| **`aegis-aec-gate`** (Model 5) | Dual-channel acoustic echo cancellation | DeepVQE Gated Filterbank | Low latency streaming | Near-end MSE / ERLE penalty |

## 3. Data Ingestion & Split Integrity

1. **Split-Segregated Shards**: Shards are generated strictly per-partition (`se-train-*.tar`, `se-val-*.tar`, `se-gentest-*.tar`). Clean speech and environmental noise from generalization sets (WHAM, MUSAN, LibriSpeech) are strictly isolated and never leak into `train` or `val`.
2. **Sync-Tier Down-Weighting**: Up-sampled 16kHz audio (Tier 3) is automatically down-weighted ($0.25\times$) relative to native 48kHz recordings ($1.00\times$) during shard sampling via `training.data.weighted_shard_sampler`.
3. **Class Balancing & Gunfire Real-Data Alignment**:
   - Thin military noise classes (`tank_tracked`, `artillery_howitzer`, `jet_cockpit`) receive explicit oversampling multipliers (`6.0x`, `5.0x`, `4.0x`).
   - `gunfire` and `gunshot_firearm` are set to `2.5x` oversampling, verified by `data_forge.verifier.gunfire_audit` across actual on-disk clips from the 3 real implemented fetchers (`gunshot_dryad`, `mad`, `noisex92`).
   - Added to `DISCLOSED_WEAK_CLASSES` in `worst_class_checkpoint_selector.py` to prevent performance regression on combat ballistics.
4. **Combat Audio Augmentation (Zero Synthetic Data)**:
   - Multi-shot compositing: concatenates independent real gunfire recordings from Dryad to simulate automatic fire and multi-shooter engagements without synthetic audio generators.
   - Lowers gunfire SNR mixing floor to `-15dB` to match close-proximity ballistic shockwaves.
   - RIR convolution probability increased to `~1.0` for ballistic audio.
5. **Canonical Streaming Chunker (`training/data/streaming_chunker.py`)**:
   - Standardizes 480-sample (10ms @ 48kHz) streaming chunk parameters across training, QAT calibration, and runtime inference.

## 4. Hardware Optimization & Training Dynamics

### 4.1 Blackwell GB10 128GB Unified Memory Utilization
- **Native `bf16` AMP**: Full mixed precision in `torch.bfloat16` without requiring gradient loss scaling, avoiding dynamic underflow/overflow scaling overheads.
- **Gradient Accumulation & Large Effective Batches**: Ingests 4.0-second 48kHz clips (192,000 samples each) with configurable `gradient_accumulation_steps=4`, allowing effective batch sizes of 64 to 128+ to maximize tensor core saturation across unified memory.

### 4.2 Quantization-Aware Training (QAT) from Epoch 1
- **Platform-Adaptive Co-Design**: Fake-quantization observers are inserted before the first training step so model weights co-adapt to quantized representations.
- **Selective Module Wrapping**: Conv1d, Conv2d, and Linear layers receive fake-quant observers, while recurrent modules (`nn.GRU`) are preserved unquantized, preventing PyTorch state tuple return crashes.
- **Dual-Platform Export**:
  - **Platform A (ARM / Jetson CPU)**: `convert_qat()` generates INT8 deployment models with QNNPACK / FBGEMM backend.
  - **Platform B (NVIDIA GPU / TensorRT)**: Dedicated export via `inference.engines.onnx_engine.export_platform_b_tensorrt()` supports FP16/INT8 with IO binding and TensorRT optimization.

### 4.3 CleanUMamba Knowledge Distillation (Training-Time Only)
- During `aegis-se-primary` fine-tuning, a frozen CleanUMamba teacher (`aegis-se-crosscheck`) runs alongside student forward passes.
- `DistillationLoss` computes L2 distance on magnitude spectrograms:
  $$\mathcal{L}_{\text{distill}} = \text{MSE}\left(|X_{\text{student}}|, |X_{\text{teacher}}|\right)$$
- The complementary inductive bias between SSM long-range recurrence and Conv1d local receptive fields boosts suppression accuracy on thin classes with **zero inference overhead**.

### 4.4 Model 2 Lookahead Output-Delay Buffer
- `DeepFilterNet3Wrapper` in `training/models/model_loader.py` implements an output-delay streaming buffer (`_pending_input`, `_output_delay_buffer`).
- Chunk $N$ is buffered and processed using chunk $N+1$'s leading samples as real right-context, emitting chunk $N$'s output upon arrival of chunk $N+1$.
- Causal first-chunk startup behavior and explicit 4-tuple forward pass for ONNX stateful tracing.

### 4.5 Dual-Metric Worst-Class Checkpoint Guard (`training/callbacks/worst_class_checkpoint_selector.py`)
- Tracks class-specific validation performance and rejects checkpoints where:
  $$\Delta \text{PESQ}_{\text{fragile}} > 0.05 \quad \text{or} \quad \Delta \text{SNR}_{\text{fragile}} > 1.0\text{ dB}$$
- Monitors weak classes: `rotor_vehicle_drone`, `wind_rotor_gap`, and `gunshot_firearm`.

### 4.6 SpecMix & EMA Tracking
- **SpecMix**: Dynamic spectral replacement on noisy mixtures preserving clean targets.
- **EMA Tracking**: Exponential Moving Average shadow weights ($\beta = 0.999$) tracked across training.

## 5. Loss Formulation (`training/losses/multires_loss.py`)

The total speech enhancement loss combines multi-resolution STFT distance, phase-sensitive complex spectral loss, framewise local SNR, and speech-presence-gated SDR:

$$\mathcal{L}_{\text{total}} = 500 \cdot \mathcal{L}_{\text{mag}}^{(\gamma=0.3)} + 500 \cdot \mathcal{L}_{\text{cplx}} + 10^{-3} \cdot \mathcal{L}_{\text{local\_snr}} + \lambda_{\text{sdr}} \mathcal{L}_{\text{sdr}} + \lambda_{\text{distill}} \mathcal{L}_{\text{distill}} + \alpha \mathcal{L}_{\text{si\_snr}} + \beta \mathcal{L}_{\text{stft\_cons}}$$

### Speech-Presence-Gated SDR Penalty (Zero Speech Cutting)
- Standard SDR loss penalizes absolute gain distortion:
  $$\text{SDR} = 10 \log_{10} \frac{\|s\|^2}{\|s - \hat{s}\|^2}$$
- `_compute_speech_mask()` uses a Hann-windowed bandpass filter across the speech formant band (300–4000 Hz) to eliminate spectral leakage.
- Speech-active frames receive a `2.5x` boosted SDR penalty (`speech_presence_sdr_boost=2.5`), ensuring aggressive noise suppression never clips vocal energy or vocal tract formants.

## 6. Runtime Safeguards & Multi-User Backend

### 6.1 Escalation Router Safeguards (`inference/runtime/escalation_router.py`)
1. **Intelligibility Floor Safeguard**: During speech-dominant frames, dry audio energy is retained at $\ge 15\%$ (`intelligibility_floor=0.15`), guaranteeing voice intelligibility even under extreme suppressions.
2. **Asymmetric Mode Hysteresis**: Escalation entry is immediate (1 chunk) for ballistic transients; bypass entry requires `15` consecutive high-SNR clean frames (~150ms) to prevent premature bypass transitions during brief speech pauses.
3. **Lazy-Load / Idle-Unload**: Escalation model is auto-loaded on demand and unloaded after `30.0s` idle, keeping GPU memory strictly within the ≤4–8GB deployment envelope.

### 6.2 Multi-User Backend Subsystem (`backend/`)
- **`backend.session_manager.SessionManager`**: Per-user session tracking consuming < 50 KB memory per user.
- **`backend.batch_inference.BatchInferenceEngine`**: Batches streaming frames across concurrent active sessions through shared neural network weights.
- **`backend.transport.AsyncStreamHandler`**: Bounded async streaming queue with PCM-16 serialization and automatic backpressure handling.

## 7. CLI Execution Commands

Run on the dedicated ML training workstation:

```bash
# Model 1: Train Primary Real-Time SE (QAT from Epoch 1, bf16 AMP, Distillation)
python -m training.scripts.train_se_primary [--resume PATH]

# Model 2: Train Escalation SE (Lookahead output delay, low-SNR weighted)
python -m training.scripts.train_se_escalation [--resume PATH]

# Model 3: Train State-Space Cross-Check (CleanUMamba)
python -m training.scripts.train_se_crosscheck [--resume PATH]

# Model 4: Train 3-Way Environment & Escalation Classifier
python -m training.scripts.train_classifier [--resume PATH]

# Model 5: Fine-Tune Acoustic Echo Cancellation (requires explicit --force)
python -m training.scripts.train_aec --force

# Export Models to ONNX / TensorRT:
python -m inference.scripts.export_onnx --model aegis-se-primary --platform platform_a
python -m inference.scripts.export_onnx --model aegis-se-primary --platform platform_b --fp16

# Run Gunfire Data Audit:
python -m data_forge.verifier.gunfire_audit
```
