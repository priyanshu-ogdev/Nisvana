# Project AEGIS — Machine Learning Training Pipeline Architecture

## 1. Executive Summary

The Project AEGIS Training Pipeline is an end-to-end, reproducible deep learning framework for training, fine-tuning, and evaluating active noise cancellation (ANC), speech enhancement (SE), and acoustic gating models. It ingests standardized 48,000 Hz WebDataset shards generated by the AEGIS Data-Forge and orchestrates 5 specialized model branches optimized for edge execution on high-stress defence acoustic environments.

---

## 2. Five Specialized Model Branches

| Model Key | Target Role | Architecture | Lookahead / Latency | Loss Stack |
| :--- | :--- | :--- | :--- | :--- |
| **`aegis-se-primary`** (Model 1) | Real-time streaming speech enhancement | DeepFilterNet3 (causal ERB filterbank + complex deep filtering) | **0 ms lookahead** (zero algorithmic delay) | Multi-Resolution STFT + Framewise Local SNR + (Opt-in SI-SNR) |
| **`aegis-se-escalation`** (Model 2) | High-difficulty low-SNR / blast speech enhancement | DeepFilterNet3 (high-capacity semi-causal configuration) | **40 ms lookahead** (`df_lookahead=2`, `conv_lookahead=2`) | Multi-Resolution STFT + Framewise Local SNR |
| **`aegis-se-crosscheck`** (Model 3) | Architectural cross-validation & GPU fallback | CleanUMamba (Selective State Space U-Net backbone) | Linear $\mathcal{O}(L)$ state-space representation | Full STFT Multi-Resolution Spectral Loss |
| **`aegis-clf-gate`** (Model 4) | Real-time acoustic environment & escalation classifier | 1D CNN + Adaptive Pooling (MobileNetV3-Audio class) | Fast sub-segment classification | Weighted Cross-Entropy over 3 collapsed classes (`harmonic`, `impulsive`, `speech_dominant`) |
| **`aegis-aec-gate`** (Model 5) | Dual-channel acoustic echo cancellation | DeepVQE Gated Filterbank | Low latency streaming | Near-end MSE / ERLE penalty |

## 3. Data Ingestion & Split Integrity

1. **Split-Segregated Shards**: Shards are generated strictly per-partition (`se-train-*.tar`, `se-val-*.tar`, `se-gentest-*.tar`). Clean speech and environmental noise from generalization sets (WHAM, MUSAN, LibriSpeech) are strictly isolated and never leak into `train` or `val`.
2. **Sync-Tier Down-Weighting**: Up-sampled 16kHz audio (Tier 3) is automatically down-weighted ($0.25\times$) relative to native 48kHz recordings ($1.00\times$) during shard sampling via `training.data.weighted_shard_sampler`.
3. **Class Balancing Factors**: Thin military noise classes (`tank_tracked`, `artillery_howitzer`, `jet_cockpit`) receive explicit oversampling multipliers (`6.0x`, `5.0x`, `4.0x`) to counterbalance large ambient noise collections.
4. **Metadata Survival**: Each shard sample contains `{clip_id}.json` sidecars preserving `split`, `unified_class`, `sync_tier`, and measured `snr_db` throughout streaming DataLoader iteration.

## 4. Advanced Training Dynamics & SOTA Upgrades

### 4.1 Dual-Metric Worst-Class Checkpoint Guard (`training/callbacks/worst_class_checkpoint_selector.py`)
- Standard checkpoint selection optimizes aggregate validation loss, allowing thin, fragile defence classes (`rotor_vehicle_drone`, `wind`) to severely degrade without impacting the global mean.
- The AEGIS Worst-Class Checkpoint Selector tracks class-specific performance and rejects checkpoints where:
  $$\Delta \text{PESQ}_{\text{fragile}} > 0.05 \quad \text{or} \quad \Delta \text{SNR}_{\text{fragile}} > 1.0\text{ dB}$$
- **Unconditional Banking**: Class-level high-water marks are updated on every step (`max(prior, current)`), preventing regressions from slipping past when the global aggregate stays flat.

### 4.2 SpecMix Dynamic Masking (`training/data/spec_augment.py`)
- Replaces rectangular spectral mask regions with random noise slices rather than zeroing bins, maintaining realistic energy floors without introducing silence artifacts. Applied exclusively to noisy mixtures, preserving clean targets untouched.

### 4.3 Exponential Moving Average (EMA) (`training/callbacks/ema.py`)
- Maintains shadow weights with decay $\beta = 0.999$ for Models 1–3, regularizing optimization trajectories. Configured as an explicit on/off ablation toggle to compare against non-averaged iterates.

### 4.4 SNR Curriculum Scheduling (`training/schedulers/snr_curriculum.py`)
- Configurable SNR sampling distribution shifts dynamically from high-SNR (easy) to low-SNR (hard) across training epochs, with direction configurable for empirical validation.

## 5. Loss Formulation (`training/losses/`)

The speech enhancement loss combines spectral magnitude distance, phase-sensitive complex spectral loss, and framewise local SNR:

$$\mathcal{L}_{\text{total}} = 500 \cdot \mathcal{L}_{\text{mag}}^{(\gamma=0.3)} + 500 \cdot \mathcal{L}_{\text{cplx}} + 10^{-3} \cdot \mathcal{L}_{\text{local\_snr}} + \alpha \mathcal{L}_{\text{si\_snr}} + \beta \mathcal{L}_{\text{stft\_cons}}$$

- **Vendored Routing**: Automatically routes to `df.loss.Loss` if `deepfilternet[train]` is installed.
- **Standalone Fallback**: Seamlessly falls back to PyTorch/NumPy multi-resolution implementation across FFT sizes $[256, 512, 1024, 2048]$ with Hann windowing and framewise SNR calculation ($480$-sample frame, $240$-sample hop).

## 6. CLI Execution Commands

Run on the dedicated ML training workstation:

```bash
# Model 1: Train Primary Real-Time SE (DeepFilterNet3 Streaming, 0 lookahead)
python -m training.scripts.train_se_primary [--resume PATH]

# Model 2: Train Escalation SE (DeepFilterNet3 40ms lookahead)
python -m training.scripts.train_se_escalation [--resume PATH]

# Model 3: Train State-Space Cross-Check (CleanUMamba)
python -m training.scripts.train_se_crosscheck [--resume PATH]

# Model 4: Train 3-Way Environment & Escalation Classifier
python -m training.scripts.train_classifier [--resume PATH]

# Model 5: Fine-Tune Acoustic Echo Cancellation (requires explicit --force)
python -m training.scripts.train_aec --force
```

## 7. Verification & Test Coverage

The full test suite guarantees end-to-end correctness:
```bash
python -m pytest -v tests/
```
- `tests/test_training_loop.py`: Lifecycle, checkpoint pruning, EMA shadow tracking, SpecMix, SNR curriculum, concrete trainers, and CLI scripts.
- `tests/test_training_sync.py`: Data-forge to training shard mapping, sync-tier down-weighting, and split isolation.
- `tests/test_multires_loss.py`: Multi-resolution spectral loss, framewise SNR, SI-SNR, and STFT consistency.
- `tests/test_model_architectures_and_metrics.py`: Architecture factory, tensor shapes, and numeric evaluation metrics.
