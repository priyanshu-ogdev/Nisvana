# Project AEGIS — Training Data Loading & Augmentation Code (`training/data/`)

> [!NOTE]
> **Source Code Only — No Audio Files Stored Here**
> This directory contains **Python modules** for data ingestion, WebDataset stream sampling, and on-the-fly spectrogram augmentation.
> All actual audio data, raw corpora, standardized pools, and `.tar` shards are stored exclusively in the root **[`data/`](file:///d:/Nisvana/data)** directory.

---

## 1. What This Folder Contains

| File | Purpose | Key Responsibilities |
| :--- | :--- | :--- |
| **[`weighted_shard_sampler.py`](file:///d:/Nisvana/training/data/weighted_shard_sampler.py)** | Shard Ingestion & Sample Weighting | Connects PyTorch DataLoader streams to `data/shards/speech_enhancement/`. Reads per-sample metadata sidecars (`{clip_id}.json`), applies Sync-Tier down-weighting ($0.25\times$ for 16kHz upsampled audio), and applies class oversampling factors ($6\times$ for tanks, $5\times$ for howitzers/drones/wind, $4\times$ for jets). |
| **[`spec_augment.py`](file:///d:/Nisvana/training/data/spec_augment.py)** | SpecMix Dynamic Augmentation | Applies on-the-fly dynamic time-frequency masking on mixture spectrograms. Fills masked regions with ambient noise slices rather than zeros to preserve physical acoustic energy floors. Applied exclusively to mixtures; clean target speech remains 100% untouched. |
| **`__init__.py`** | Package Exports | Cleanly exports `compute_sample_weight`, `build_weighted_se_dataset`, and `apply_spec_mix`. |

## 3. Data Mapping Across Models

1. **Models 1, 2, 3 (`aegis-se-primary`, `aegis-se-escalation`, `aegis-se-crosscheck`)**:
   - Ingest from: `data/shards/speech_enhancement/se-train-*.tar`
   - Content: Paired audio triplets (`noisy.wav`, `clean.wav`, `rir.wav`, `json`).
   - Weighted by: `weighted_shard_sampler.build_weighted_se_dataset()`.
2. **Model 4 (`aegis-clf-gate`)**:
   - Ingests from: `data/shards/classifier/clf-train-*.tar`
   - Content: Single audio clips (`wav`) and 3-way taxonomy labels (`json`).
   - Loaded by: `AegisClassifierIterableDataset`.
3. **Model 5 (`aegis-aec-gate`)**:
   - Ingests from: `data/shards/aec/aec-train-*.tar`
   - Content: Multi-channel quadruplets (`mic.wav`, `farend.wav`, `nearend.wav`, `echo.wav`, `json`).
   - Loaded by: `AegisAecIterableDataset`.
